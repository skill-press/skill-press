# @skill-press/cli 0.0.0

This package version is an inert, one-time reservation of the canonical Skill Press CLI name.

It contains no executable, JavaScript, type declarations, lifecycle scripts, dependencies, or
library API. Do not install or depend on version `0.0.0`. The first formal CLI release is intended
to be `0.1.0`, published from `skill-press/skill-press` through npm Trusted Publishing with GitHub
Actions provenance.

Visit [skill-press.com](https://skill-press.com) or the
[canonical repository](https://github.com/skill-press/skill-press) for current release information.
